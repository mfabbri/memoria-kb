# T33 Human Review Response Template

Data revisione: `YYYY-MM-DD`

Stato: template compilabile per la revisione umana del racconto T33. Questo
file non contiene un verdetto reale finche' non viene compilato da un revisore
umano e non autorizza pubblicazione, bando, importo o finanziatore.

## Perimetro della revisione

La revisione riguarda solo il racconto in sei schermate della presentazione
T33. Non approva fatti storici, non modifica la golden run, non applica
`ProfilePatch`, non crea verified facts canonici e non rende pubblicabile alcuna
scheda.

## Conferme Di Guardrail

Il revisore conferma esplicitamente:

- [ ] la presentazione non descrive schede preview come pubblicabili;
- [ ] coorte pilota, golden run a tre casi e patrimonio disponibile restano
      distinti;
- [ ] non sono stati introdotti bando, importo o finanziatore;
- [ ] non viene promesso il completamento dei 57 profili;
- [ ] il caso Andreoli mostra collegamenti e dubbi, non una biografia conclusa;
- [ ] nessun `ProfilePatch` viene applicato;
- [ ] nessun verified fact canonico viene creato;
- [ ] nessun profilo canonico viene modificato.

## Limiti

Questo template non e' una decisione compilata. Deve restare vuoto o marcato
come bozza finche' non viene usato in una sessione di revisione umana effettiva.
Nessun contenuto di questo file autorizza pubblicazione storica, promozione di
claim, modifica del descriptor attivo o scritture nel data root esterno.
