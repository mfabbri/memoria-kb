# Chunk Classification LLM Contracts

Contratti versionabili per la classificazione preview-only dei
`PhysicalDocumentChunk`.

Questi file definiscono prompt e schema JSON per output di triage non
revisionati. Non autorizzano produzione di claim, profili, patch o fatti
verificati.

Il runtime `memoria-engine` risolve questa directory come posizione primaria.
Il percorso legacy `memoria-engine/ricerche/llm_prompts` non e' piu' un
fallback operativo.
